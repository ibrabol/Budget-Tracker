# My Budget Tracker

## Project Description

My Budget Tracker is a simple web application interface designed to help users record and organize their daily expenses.

## Project Files

* **index.html:** Contains the structure of the website, including the expense form, category dropdown, expense table, image and embedded video.
* **style.css:** Controls the appearance of the website, including colors, spacing, table formatting, hover effects and responsive design.
* **README.md:** Explains the purpose and structure of the project.

## Features

* Expense entry form
* Five expense category options
* Expense table with sample records
* Budgeting image and embedded video
* Responsive layout
* Advanced CSS selectors

## Technologies Used

* HTML5
* CSS3

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
